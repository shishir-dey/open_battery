# Open Battery (Generic Chinese BMS Companion App)

## Setup and Build

### Prerequisites
- Flutter SDK
- Dart SDK
- Android Studio / Xcode

### Setup
```
git clone https://github.com/shishir-dey/open_battery
cd open_battery
flutter pub get
```

### Run
```
flutter run
```

### Build

Android:
```
flutter build apk --release
```

iOS:
```
flutter build ios --release
```

Web:
```
flutter build web --release
```
